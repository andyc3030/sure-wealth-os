# Research Output Contract

Every completed research run must be capable of producing the following table:

| Theme | Source | Type | Date | Authority | Evidence quality | Key finding | Supports thesis? | Challenges thesis? | Investment implication |
|---|---|---|---|---:|---:|---|---|---|---|

It must also produce a **Top 25 Source Set** selected by the repository's source-ranking policy.

## Portfolio implications

The final advisory output classifies positions as:

- increase;
- hold;
- reduce;
- exit;
- new position for consideration;
- avoid despite strong narrative;
- missing thematic exposure.

## Recommendation evidence

Every recommendation must be traceable through:

```
InvestmentRecommendation
        ↓
InvestmentRecommendationClaim
        ↓
ResearchClaim
        ↓
ResearchEvidence
        ↓
ResearchSource
        ↓
raw-source / URL / publication / retrieval metadata
```

## Required recommendation analysis

A recommendation cannot pass the review gate solely on thematic fit.

It must address:

- valuation;
- competitive position;
- capital intensity;
- cash generation;
- balance-sheet quality;
- downside;
- principal risks;
- correlation/overlap with existing holdings;
- counter-thesis evidence.

## Evidence discipline

- no pseudo-data;
- no unsupported assumptions;
- no invented prices;
- no invented research findings;
- material factual claims require source provenance;
- conflicting evidence must be disclosed;
- insufficient evidence must be labelled **INSUFFICIENT EVIDENCE**.

## Advisory-only boundary

The output may contain portfolio advice, but it cannot initiate or authorize execution.
